# SquareLine Studio 1.5.4 Documentation

Welcome to the official documentation of SquareLine Studio!

[![](/img/slbanner2.png)](/img/slbanner2.png)

## The design tool for Designers and Developers

Squareline Studio is a multiplatform designer tool that helps designers and developers to work fast and in an efficient way. Our goal is to help designers and developers use the same file format and SquareLine Studio makes it possible by creating a perfect code to your project. Whether you are working in C or Python language, you can export the code for both.
