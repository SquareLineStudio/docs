# Error Panel

The error panel primarily displays errors where a parameter is missing in an event, animation, or style part. Errors listed here are also visible in the Hierarchy panel, where a red dot appears before the widget containing the error.

### The error panel list includes

- **Screen/Component** - Screens or components where the error appears
- **Widget** - The name of the widget with the error
- **Property** - The name of the erroneous parameter
- **Description** - A detailed description of the error
