# Preferences

Program settings can be found in Preferences menu.

- **UI scale** - Zoom in or out the UI design.
- **Start in maximized window** - Forces application to start maximized when enabled. When disabled, window opens in last closed size.
- **Autosave** - The software automatically saves the project periodically. This function not only overwrites the project file but also saves files created at different times in the autosave folder of the software.
- **Check for updates** - The title and current version of the program can be found here, as well as the **CHECK FOR UPDATES** button with which you can check whether there is a newer version of the program.
- **Undo history size** - You can adjust how many versions the History save. The higher the number, the more memory you need on your computer.
- **Object naming** - Select whether to include the screen's name in the name of the widget by default.
- **Default align** - Select the default ALIGN of the widgets.
- **Reset UI layout** - Pressing the reset button restores the editor layout to its default state.
- **Format .spj and .ecomp files** - Whether to format the .spj and .ecomp files.
- **Licence** - You can find licence information of the program here. You can remove the current licence by clicking on the **REVOKE LICENCE** button.
- **About** - SqaureLine Studio information
- **Hot Keys** - There is a list of keyboard shortcuts which can be used in the program.
